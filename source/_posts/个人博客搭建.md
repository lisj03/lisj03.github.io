title: 个人博客搭建
---

#### 安装基本环境

1. **Node.js + npm**（JavaScript 运行环境）
2. **Git**
3. **GitHub 账号**

#### **安装 Hexo**

1. 安装 Hexo CLI
   ```bash 
   npm install -g hexo-cli
   ```

2. 创建一个博客文件夹（myblog）
   ```bash 
   mkdir myblog
   cd myblog
   hexo init
   npm install
   ```

3. 打开浏览器输入：[http://localhost:4000](http://localhost:4000 "http://localhost:4000")，能看到初始页面
   ```markdown 
   hexo server
   ```


#### 选择并更换自己喜欢的主题

- 网址： [https://hexo.io/themes/](https://hexo.io/themes/ "https://hexo.io/themes/")

1. 安装主题
   ```markdown 
   cd themes
   git clone https://github.com/theme-next/hexo-theme-next next

   ```

2. 修改配置文件\_config.yml
   ```bash 
   cd ..
   vim _config.yml
   ```

   修改theme: 行为
   ```yaml 
   theme: next（选择的主题名称）
   ```


#### wolai导出文档

#### **移动 Markdown 文件到 Hexo 项目根目录下的source/\_post文件夹**

- **Hexo 项目根目录**：～/myblog

#### **添加 front-matter 头部信息**

- 在最上方加上这样的内容
  ```yaml 
  ---
  title: 我的第一篇博客文章
  date: 2025-09-04 21:00:00
  tags: [Wolai, 笔记]
  categories: 生活记录
  ---
  ```


#### 处理wolai导出的图片

- 把所有图片移动到 source/images/和博客titile同名的文件夹下
- 修改 Markdown 中图片路径：
  ```markdown 
  ![](/images/[title]/image-1.png)
  ```


#### 运行

1. cd到博客路径
   ```bash 
   cd ~/myblog
   ```

2. 运行
   ```typescript 
   hexo server
   ```

   ![](<image/个人博客搭建/截屏2025-10-04 21.22.16_USItI-fEvG.png>)
3. 打开浏览器输入：[http://localhost:4000](http://localhost:4000 "http://localhost:4000")，能看到初始页面
